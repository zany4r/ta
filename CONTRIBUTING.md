# Contributing to Translate Anything

Contributions are welcome!

## Development Setup

```bash
npm install
npm run build
npm test
```

## Ideas for Contributions
- Additional console ROM header parsers (PC Engine, WonderSwan, Dreamcast GDI, GameCube GCM)
- Additional encoding tables (Shift-JIS / EUC-JP / custom RPG tilemaps)
- Additional README translations in `docs/readme/`
- New engine bridges in `bridge/`
